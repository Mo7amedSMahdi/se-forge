# User stories (approved 2026-10-07)
## E1-S2 Book a slot
As a patient I want to book a free slot so that I see the doctor.
- AC1: Given a free slot, when I book it, then it is mine and no longer free.
- AC2: Given a slot someone else booked, when I try to book it, then I get "slot taken" (409) and nothing changes.
